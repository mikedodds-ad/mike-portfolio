# mike-portfolio

Mike's art-direction portfolio. A static site: no build step.

## Edit the words
Every word on the site is in **`content.js`**.

1. Open `content.js` here on GitHub.
2. Click the pencil icon (Edit this file).
3. Change the text between the quote marks.
4. Click **Commit changes**.

The live site updates in about 30 seconds. If a page goes blank after an edit,
a quote mark or comma is usually missing; check the rules at the top of `content.js`.

## Files
- `index.html`: the design, layout and motion
- `content.js`: all text (campaigns, About me facts, country stories)
- `photo.jpg`: the background photo
